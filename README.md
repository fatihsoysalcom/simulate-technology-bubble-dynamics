# Simulate Technology Bubble Dynamics

This Python script simulates the lifecycle of a technology bubble in a simplified financial market. It demonstrates how an asset's market price can detach from its intrinsic value due to speculation and herd mentality, leading to a bubble that eventually bursts, followed by a period of recovery or stabilization. The simulation highlights the core concepts of technology bubbles discussed in the article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run it from your terminal using Python:
`python main.py`
